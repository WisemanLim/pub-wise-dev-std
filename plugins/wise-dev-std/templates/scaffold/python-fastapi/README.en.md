## Quick Start

```bash
# 1. Create virtualenv and install dependencies
uv sync

# 2. Copy environment file
cp .env.local .env

# 3. Install deps / build + start infra (Postgres :5432 + Redis :6379) + host processes (background)
make local-build && make local-all

# 4. Tail logs (Ctrl-C stops the tail only; or run `uv run uvicorn app.main:app --reload` directly)
make local-logs
# → http://localhost:8000
# → Swagger UI: http://localhost:8000/docs
# → ReDoc:      http://localhost:8000/redoc
```

## Make Targets

```
make <target> [ENV=<env>]
```

| Target | Description |
|--------|-------------|
| `make preflight` | Check runtime/tool version compatibility |
| `make test` | Run tests (`uv run pytest`) |
| `make deploy` | Deploy to Kubernetes via Helm |
| `make help` | List targets |
| `make local-build` | [local] Install deps / host build (`uv sync`) |
| `make local-all` | [local] Start infra(docker) + **honcho (or `PROC_MGR=pm2`)** host processes together (background) |
| `make local-logs` | [local] Tail aggregated logs (Ctrl-C stops the tail, processes keep running) |
| `make local-stop` | [local] Stop host processes + tear down infra |
| `make local-restart` | [local] Restart host processes (infra stays up) |
| `make local-ps` | [local] Process status (`honcho check` / `pm2 ls`) |
| `make <env>-all` | [dev\|staging\|prod] Start infra + app containers (`docker compose --env-file .env.<env> --profile app`) |
| `make <env>-build` | [dev\|staging] Rebuild image and start (not provided for prod — CI/CD artifact) |
| `make <env>-logs` | [dev\|staging\|prod] Tail container logs (`SVC=` for one service) |
| `make <env>-stop` | [dev\|staging\|prod] Tear down app + infra |
| `make <env>-restart` | [dev\|staging\|prod] Restart containers (`SVC=` for one service) |
| `make <env>-ps` | [dev\|staging\|prod] Container status |
| `make db-migrate [ENV=<env>]` | Apply migrations (default `uv run alembic upgrade head`, override with `MIGRATE="..."`) |
| `make db-seed [ENV=<env>]` | Load seed data (default `uv run python -m app.seed`, override with `SEED="..."`) |
| `make db-reset [ENV=<env>]` | Reset DB + migrate (local = delete SQLite file; others = recreate postgres `schema public`; refused for prod) |
| `make db-fresh [ENV=<env>]` | `db-reset` + `db-seed` (e.g. `make db-fresh ENV=dev`) |

### Local multi-process (honcho by default, pm2 as an alternative)

Use when running a worker (arq/celery/rq) alongside the web (uvicorn) process. Defined by the
`web:`/`worker:` lines in `Procfile.dev`. honcho is a dev dependency (installed by `uv sync`) and
runs **daemonized in the background** (nohup+pidfile, `.make/honcho.pid`), controlled via
`local-logs`/`local-stop`/`local-restart`.

```bash
make local-all       # start infra + honcho in the background
make local-logs      # tail aggregated logs
make local-stop       # stop everything
# add a worker: uncomment the 'worker:' line in Procfile.dev
```

To use pm2 instead (requires Node/npx):

```bash
make local-all PROC_MGR=pm2       # start pm2 daemon from ecosystem.config.cjs
make local-logs PROC_MGR=pm2
make local-stop PROC_MGR=pm2
```

Override environment:

```bash
make dev-build          # rebuild image + start from .env.dev (dev|staging only)
make dev-all            # full app+infra stack from .env.dev
make staging-all        # full app+infra stack from .env.staging
```

## Environment Variables

| File | Purpose |
|------|---------|
| `.env.local` | Local development (exclude from Git) |
| `.env.dev` | Dev server |
| `.env.staging` | Staging |
| `.env.prod` | Production (manage secrets via CI/Vault) |

Key variables:

| Variable | Default | Description |
|----------|---------|-------------|
| `POSTGRES_USER` | `app` | DB user |
| `POSTGRES_PASSWORD` | `app` | DB password |
| `POSTGRES_DB` | `app` | DB name |
| `DATABASE_URL` | — | Full connection string |

> **Warning**: Never commit real secrets to `.env.prod`.

## Running

### Local Development

```bash
make local-all    # infra + host processes in the background (or run `uv run uvicorn app.main:app --reload` directly)
make local-logs   # tail logs
```

### Testing

```bash
make test
# with coverage:
uv run pytest --cov=app --cov-report=html
```

### DB Migrations (Alembic)

```bash
uv run alembic upgrade head
uv run alembic revision --autogenerate -m "add users table"
```

## Build & Deploy

### Docker Image

```bash
make staging-build   # rebuild image + start full stack from .env.staging
make staging-logs
```

### Kubernetes (Helm)

```bash
make deploy
# or:
helm upgrade --install {{PROJECT_NAME}} ./deploy/helm \
  --set image.tag=$(git rev-parse --short HEAD)
```
